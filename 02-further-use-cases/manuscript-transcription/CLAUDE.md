# CLAUDE.md — Manuscript transcription

Project-level instructions loaded when Claude Code starts in this folder. In
Cowork, ask Claude to read this file first.

## What this project is

A worked example of transcribing manuscript page images, from Old English to
the nineteenth century, and presenting each page beside its transcription. See
[summary.md](summary.md).

## How to work in this project

- Page images in `inputs/` are read-only. New files go in `outputs/`.
- Follow [operations/01-transcribe-page.md](operations/01-transcribe-page.md)
  exactly, including its conventions for letters, deletions, insertions, and
  uncertain readings.
- Transcribe what is visible. If you recognize a text, say so, and mark every
  reading that comes from memory rather than from the image as
  `[supplied: …]`. Never fill a gap silently, and never correct a draft toward
  a published version.
- Record marginalia and later hands separately from the main text.
- Do not claim a transcription has been checked against an edition.
- When you are unsure of a reading, say so and list it under Uncertainties. An
  honest `[illegible]` is more useful than a confident guess.
