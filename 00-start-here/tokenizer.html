Each colored segment is one token, and each number is that token's ID in the model's vocabulary. The model never sees letters or words, only this sequence of numbers. These tokens come from OpenAI's GPT-4o tokenizer, the same view as tiktokenizer.vercel.app. Claude uses its own tokenizer, which is not public; the splits differ in detail but work the same way.
